# 本地白名单管理系统（通用脱敏版）

一个面向个人、本机使用的轻量白名单管理工具。无需数据库和 Web 框架，使用 Python、原生 HTML/JavaScript 与 Excel 即可完成批量导入、查重、查询维护、软删除、按日期导出和写前备份。

> 本目录不包含任何真实业务数据。首次启动会自动创建空白 `白名单数据.json` 和 `白名单.xlsx`。

## 文件

- `本地白名单管理系统.py`：本地 HTTP 服务与业务逻辑。
- `whitelist.html`：浏览器操作页面。
- `requirements.txt`：唯一第三方依赖 `openpyxl`。
- `test_whitelist.py`：使用临时目录和虚构数据的基础测试。

## 运行

```bash
cd "vibe coding"
python3 -m pip install -r requirements.txt
python3 本地白名单管理系统.py
```

浏览器打开：

```text
http://127.0.0.1:8210/whitelist.html
```

需要换端口时：

```bash
python3 本地白名单管理系统.py 8211
```

## 数据初始化

- 没有任何数据文件：自动创建空库，不预置示例记录。
- 没有 JSON、但已有 `白名单.xlsx`：从 Excel 导入记录。
- JSON 为 0 字节或只有空白：按首次运行重新初始化。
- JSON 内容损坏：停止并提示修复，不会擅自清空原文件。

日常变更请通过页面完成。JSON 是唯一主数据，Excel 是自动生成的输出文件，不要同时手工维护两份。

## 功能

- 批量粘贴解析，区分新增、库中已有、本批重复和格式错误；
- 确认入库前预览，服务端写入时再次校验和查重；
- 关键字、日期范围查询，单条编辑和批量修改；
- 软删除、退出日期、备注和恢复；
- 按日期预览并导出新增或退出 Excel；
- 每次写入前备份旧 JSON 与 Excel；
- JSON 使用临时文件原子替换，降低写入中断风险。

## 测试

`test_whitelist.py` 是开发后的自动检查工具，**不是系统运行必需的组件**。日常使用只需启动 `本地白名单管理系统.py`，不需要运行测试文件。

修改代码后，可执行：

```bash
python3 test_whitelist.py
```

测试覆盖：空目录初始化、空白 JSON 初始化、批量解析与查重、Excel 生成与写前备份，以及损坏 JSON 的防覆盖保护。看到 `Ran 5 tests ... OK` 表示全部通过。

测试只操作系统临时目录和虚构号码，不读取或修改本目录的真实数据文件。

## 安全边界

- 默认只监听 `127.0.0.1`，不要在没有认证和访问控制时改为 `0.0.0.0`。
- 适合单用户、低频率操作；多人共享应改用数据库、唯一约束、认证和审计。
- 备份与主数据位于同一目录，不能代替离线备份和恢复演练。
- 示例号码均为虚构，不要向公共 AI 或公开仓库提交真实名单。
- 导出只是数据整理结果，不替代人工审核和业务审批。
