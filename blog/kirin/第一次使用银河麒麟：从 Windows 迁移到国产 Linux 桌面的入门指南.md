# 第一次使用银河麒麟：从 Windows 迁移到国产 Linux 桌面的入门指南

第一次打开银河麒麟，很多人会下意识地寻找熟悉的 Windows 操作入口：软件应该去哪里下载？文件存在哪个盘？为什么有些操作需要输入密码？终端里的命令是不是都必须记住？

其实，日常办公并不依赖大量命令。开始菜单、任务栏、文件管理器和系统设置仍然是我们熟悉的图形界面，真正需要改变的是对文件目录、权限和软件安装方式的理解。

这篇文章根据我此前编写的银河麒麟内部培训手册重新整理，删去单位专用软件和内部环境内容，保留最通用的入门知识，作为银河麒麟专题的开篇。

> 适用对象：第一次接触银河麒麟桌面系统的办公用户和初学者。
> 主要环境：银河麒麟桌面 V10，UKUI 桌面。不同版本的菜单名称和默认软件可能略有差异。

## 一、先认识银河麒麟：它是一款 Linux 桌面系统

银河麒麟（Kylin）是麒麟软件推出的国产操作系统。我们日常使用的桌面版通常采用 UKUI 桌面，提供开始菜单、任务栏、系统托盘、文件管理器等常见组件。

对普通用户来说，文档处理、网页浏览、即时通信、音视频播放等任务，仍然主要通过图形界面完成。Linux 并不意味着每天都要对着黑色窗口输入命令。

需要注意的是，**银河麒麟桌面版与服务器版的软件管理方式可能不同**。桌面 V10 常见 `apt` 和 `.deb` 软件包；服务器环境也可能使用 `dnf` 或 `yum`。开始操作前，应先确认自己的系统版本，不要把不同发行版的命令混用。

## 二、从 Windows 转过来，先改变三个习惯

### 1. 不再用“C 盘、D 盘”理解全部文件

Linux 使用一棵以 `/` 为起点的目录树。硬盘、U 盘和其他分区会挂载到这棵树中的某个位置，而不是都表现为独立盘符。

常见目录如下：

| 目录 | 主要用途 |
|---|---|
| `/home/用户名` | 个人文档、下载内容和大部分用户配置 |
| `/etc` | 系统与服务的配置文件 |
| `/usr` | 系统程序和共享资源 |
| `/var` | 日志、缓存等经常变化的数据 |
| `/opt` | 部分第三方应用 |
| `/tmp` | 临时文件 |
| `/dev` | 设备文件 |
| `/boot` | 内核与启动相关文件 |

日常使用最重要的原则是：**个人资料优先放在自己的家目录，不要随意修改 `/etc`、`/usr` 等系统目录。**

在终端中，`~` 代表当前用户的家目录。例如，`~/Documents` 和 `/home/当前用户名/Documents` 指向同一个位置。

### 2. 软件优先从应用商店或软件仓库安装

Windows 用户通常习惯搜索软件官网，下载安装包后一路点击“下一步”。银河麒麟也支持安装包，但更推荐以下顺序：

1. 优先使用系统自带应用商店；
2. 使用系统软件仓库和 `apt`；
3. 需要厂商版本时，从官方网站下载与系统架构匹配的 `.deb` 包；
4. 确认包适用于当前银河麒麟版本，不要混用其他发行版的软件源。

安装 ARM64 笔记本时，还要注意处理器架构。为 x86_64 编译的安装包通常不能直接安装在 ARM64 系统上。

### 3. 把 `sudo` 当作一次临时授权

Linux 对系统级修改有明确的权限边界。安装软件、修改系统配置等操作，经常需要在命令前加 `sudo`，并输入当前用户密码。

```bash
sudo apt update
```

`sudo` 的意义是让这条命令临时获得管理员权限，而不是让当前会话一直处于管理员状态。遇到权限不足时，应先确认操作是否必要，不要习惯性地给所有文件开放最高权限。

## 三、终端不可怕：先学会打开和看懂提示符

打开终端通常有三种方法：

- 按 `Ctrl + Alt + T`；
- 从开始菜单搜索“终端”或“Terminal”；
- 在文件管理器的目录空白处右键，选择“在终端中打开”。

常见提示符类似：

```text
username@computer:~$
```

其中 `username` 是当前用户，`computer` 是主机名，`~` 表示家目录，`$` 表示普通用户。我们只需要在 `$` 后输入命令，不要把提示符本身一起输入。

输入命令时还有两个很实用的技巧：

- 按 `Tab` 自动补全命令和路径；
- 按上下方向键调出历史命令。

## 四、掌握这几组命令，就能完成基础排查

### 文件与目录

```bash
pwd                 # 查看当前所在目录
ls                  # 列出当前目录内容
ls -lh              # 以易读格式查看详细信息
cd ~/Documents      # 进入文档目录
cd ..               # 返回上一级目录
mkdir test          # 新建目录
cp a.txt b.txt      # 复制文件
mv b.txt c.txt      # 重命名或移动文件
```

删除命令需要格外谨慎。执行 `rm`，尤其是包含 `-r`、`-f` 或通配符的命令前，应再次确认路径，并确保重要资料已有备份。

### 系统信息

```bash
uname -a            # 查看内核与系统架构信息
hostnamectl         # 查看主机和操作系统信息
lscpu               # 查看 CPU 信息
free -h             # 查看内存使用
df -h               # 查看磁盘空间
```

### 软件管理

以下命令适用于使用 `apt` 的桌面环境：

```bash
sudo apt update             # 更新软件包索引
apt search 关键词           # 搜索软件
sudo apt install 软件包名    # 安装软件
sudo apt remove 软件包名     # 移除软件
```

`apt update` 更新的是软件包索引，并不等于把系统里所有软件都升级。

### 网络与故障信息

```bash
ip addr                     # 查看网络接口和地址
ping -c 4 223.5.5.5         # 测试基础网络连通性
journalctl -p err -b        # 查看本次启动以来的错误日志
top                         # 动态查看进程和资源占用
```

排查网络问题时，IP 能连通并不代表域名解析或应用服务一定正常，还需要继续检查 DNS、代理和具体服务状态。

## 五、几个常见问题

### 安装软件时提示“无法找到软件包”

先执行 `sudo apt update` 刷新索引，再检查软件包名称是否正确。如果仍然找不到，可能是默认仓库没有收录，也可能是软件不支持当前系统架构。不要随意添加来源不明的软件源。

### Windows 的 `.exe` 软件能直接安装吗

通常不能。应优先寻找 Linux 原生版本、网页版或功能相近的替代软件。Wine 等兼容方案可以运行部分 Windows 程序，但兼容性因软件而异，不宜把它当作所有办公软件的通用答案。

### U 盘插入后没有弹出窗口

先打开文件管理器，查看侧边栏是否出现新的卷或设备。很多情况下 U 盘已经自动挂载，只是没有额外提示。拔出前仍应执行“弹出”或“安全移除”。

### 系统越来越卡，先看什么

可以先检查 `top`、`free -h` 和 `df -h`，判断是进程占用、内存不足还是磁盘空间紧张，再结合系统日志继续定位。不要一上来就清理不认识的系统目录。

### 忘记密码或需要重装系统怎么办

如果设备由单位统一配发，建议联系系统管理员处理。密码恢复、系统重装、磁盘分区和激活方式都可能受单位安全策略约束，不宜照搬网络教程。

## 六、AI 助手可以降低门槛，但不能代替确认

现在可以把一部分 Linux 学习和排查工作交给 AI 助手，例如解释命令、分析报错、整理系统信息，甚至生成安装或备份脚本。

但涉及删除文件、修改权限、更换软件源、关闭安全组件等操作时，不能只因为命令由 AI 生成就直接执行。至少应确认：

- 命令的作用和适用系统版本；
- 路径、软件包名和参数是否正确；
- 是否会影响重要数据或单位安全策略；
- 是否有备份和可回退方案。

AI 更适合成为解释器和辅助排障工具，最终执行决定仍应由使用者作出。

## 写在最后

从 Windows 迁移到银河麒麟，不需要一开始就掌握复杂的 Linux 知识。先熟悉图形界面，理解家目录和权限边界，再掌握少量查询与安装命令，就足以应对大部分日常办公场景。

后续这个专题会继续记录银河麒麟上的真实使用经验，包括软件安装、系统升级、外设适配、故障排查和 AI 工具实践。相比堆砌命令，我更关注问题为什么会出现，以及如何留下一条能够复现、验证和回退的解决路径。
