## 写作与发布原则

1. 原始素材保存在私有 `syber` 库；整理、核验和脱敏后，才进入本仓库。
2. Gitee Markdown 是唯一长期原稿，不为每个发布平台单独维护一份文档。
3. 文章定稿后更新专题目录和本 README，再提交、推送 Gitee。
4. GitHub 只接收自动镜像，不在 GitHub 网页端直接编辑。
5. 中文文件名保留完整中文标题；对外分享 URL 时，对中文、空格和全角符号进行百分号编码。
6. 命令、报错、系统版本、设备环境和脚本须来自真实记录，不由 AI 补造。
7. 已发布到其他平台的文章，后续纠错默认只修改 Gitee 原稿，不自动创建重复平台草稿。

完整工作流程见：[WORKFLOW.md](WORKFLOW.md)。

## 内容边界

- 不发布单位内部地址、账号、访问码、设备标识和专用网络配置。
- 个人实测明确记录环境、时间和版本，不推广为普遍产品结论。
- 涉及系统服务、音频配置和高权限命令时，提供适用条件与回滚方法。
- 脚本中的设备地址、声卡名等本机参数须由读者自行替换。
