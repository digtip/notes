## 仓库说明

1. 所有修改仅在 Gitee 主仓库进行；GitHub 仓库仅为镜像备份，不做任何编辑。
2. 图片优先使用外部图床，仓库内仅保存必要的少量图片。
3. 文章发布顺序：Gitee 原文链接可访问后，再同步至 CSDN、掘金等平台。
4. AI 只负责结构化、组织语言与排版；命令、报错、系统版本和截图必须由本人核验。
